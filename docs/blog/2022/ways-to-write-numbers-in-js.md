# js中各种数字的书写方式

盘点数字字面量的书写形式与各种坑。

## 点前缀、点后缀的区别

```js
11 // 11
.11 // 0.11
11. // 11.0
```

## 八进制

```js
011 // 9
```

当你前边使用一个`0`开头的话，那么这个数字它会把它当成八进制，也就是逢八进一，那么11就是9。

```js
080 // 80
```

`0`开头的话，如果说后边有些无效数字(比如上面的8，8进制不可能出现8，逢8就要进1了)，它会把它当成十进制。

```js
0o11 // 9
0o80 // 报错
```

`0o`开头的话，也是当成8进制处理，而且是一定把它当成八进制，这种情况下你出现了无效数字，它就会报错。

## 二进制

`0b`开头就是2进制。

```js
0b11 // 3
```

## 16进制

`0x`开头就是16进制。

```js
0x11 // 17
```

## 科学计数法

11e2 是科学计数法，表示 11×10² = 1100

```js
11e2 // 11×10² = 1100
```

## 其他

```js
11.toString() // 报错
```

`11.toString()` 报错是因为 JS 把点当成小数点而非方法调用符，后面跟的字符无法构成合法小数。

```js
11 .toString() // '11'
```

写成 `11 .toString()` 加空格后就能正常运行，因为点被识别为调用方法而非小数点。这也体现出 JS 解析器如何区分数字字面量与方法调用。
